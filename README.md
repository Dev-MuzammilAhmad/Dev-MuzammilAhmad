## Featured Projects

### [DeadlineAware](https://github.com/Dev-MuzammilAhmad/DeadlineAware)

A responsive deadline tracking web application built with **React, Vite,
and Tailwind CSS**. It provides real-time database synchronization
through Firebase, automatic email notifications, and dynamic deadline
status tracking.

**Tech:** React, Vite, Tailwind CSS, Firebase, EmailJS

------------------------------------------------------------------------

### [KARIGAR.PK --- ZYNVEX Internship Project](https://github.com/Dev-MuzammilAhmad/KARIGAR.PK_ZYNVEX_Internship_Project)

A local service marketplace connecting customers with verified skilled
workers such as electricians, plumbers, carpenters, and other service
providers. Built with the **MERN Stack** with features focused on
service discovery, worker profiles, and marketplace interactions.

**Tech:** MongoDB, Express.js, React, Node.js

------------------------------------------------------------------------

### [FitNova](https://github.com/Dev-MuzammilAhmad/FitNova)

A modern fitness web application built with **React and Vite** that
allows users to browse, search, and filter 800+ exercises by muscle
group. It includes exercise detail pages with step-by-step instructions.

**Tech:** React, Vite, JavaScript, API Integration
